# Submission checklist

Target readiness: **October 30, 2026, noon America/New_York**. Submission deadline: **1 p.m. EDT** that day.

## Entrant and originality

- [x] Entrant confirmed adult, US-based solo participation and no excluded conflicts.
- [ ] Join the hackathon and complete all required Devpost fields before the deadline.
- [ ] Confirm rights/licenses for all source, assets, data, and video material; retain dependency notices.
- [ ] Include the new-work disclosure: existing foundations may be reused, but significant new work during the submission period must be explained.
- [ ] Keep the project freely accessible for judges through **December 23, 2026**, including credentials/instructions if needed. English materials are required.
- [ ] Preserve the submitted release and evidence. Do not claim ownership of prior team work.

The official submission period started August 26. Rules list judging December 9–23 and announcements around January 25, 2027. These checks derive from the [official rules](https://nebiusglobalaihackathon.devpost.com/rules).

## Runtime and submission artifacts

- [ ] Verify a genuine runtime NVIDIA-model call through Nebius Token Factory, or qualifying Nebius AI Cloud execution. Record exact model/endpoint and observed outcomes.
- [ ] Select Best Apps and Agents and demonstrate the complete, governed issue-triage workflow.
- [ ] Public repository with all needed source/assets, detectable open-source license, README setup and run instructions.
- [ ] Working public demo or test-build URL, tested from outside the development machine.
- [ ] Public YouTube video **under three minutes**, showing functioning software and explaining Nebius/NVIDIA usage.
- [ ] Description, technology attribution, significant-new-work explanation, and specific feedback on products actually used.
- [ ] All published measurements backed by evidence; fixtures, replay and injected drift clearly labelled.

See the [submission requirements](https://nebiusglobalaihackathon.devpost.com/). The [FAQ](https://nebiusglobalaihackathon.devpost.com/details/faqs) confirms that an NVIDIA call through Token Factory permits other app components to be hosted elsewhere; another inference provider alone does not qualify. City prizes require actual attendance; do not claim one without it.

## Publication and preservation

- [ ] Verify repository, demo and video while signed out; include clear testing steps.
- [ ] Submit before the deadline, verify submitted status, and retain a receipt/screenshot and final source commit.
- [ ] Freeze submitted code, video and project materials at the deadline. The [final checklist update](https://nebiusglobalaihackathon.devpost.com/updates/46207-final-stretch-here-s-your-submission-checklist) explicitly warns against post-deadline edits. Its older judging dates conflict with the rules; preserve access through the later December 23 date.
- [ ] Protect all API keys, session capabilities, and operator secrets. Check exported packets and video frames.
- [ ] Keep source, dependencies, caches, and media within the user's **4GB** cap. This is a project constraint, not a verified hackathon rule.
- [ ] Respect the user's **$25 total new paid spend cap**, use credits/free resources first, and preserve the global ledger across sessions/restarts. Session demo balances do not reset this authorization.

## Pending external access at checklist creation

Nebius onboarding/credits, a successful live NVIDIA-model call, public hosting, public repository publication, YouTube upload, and final Devpost submission require verification. Update this checklist only from observed results. No winning outcome is guaranteed.
